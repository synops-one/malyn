About this control surface
The admin UI binds to this computer’s loopback address and uses a temporary session token. It has no LAN listener, telemetry, remote fonts or hosted scripts.
The server stops after two minutes without an authenticated request. Closing the admin server or tray leaves MCP and active jobs running. Pause new tasks to stop accepting work.
